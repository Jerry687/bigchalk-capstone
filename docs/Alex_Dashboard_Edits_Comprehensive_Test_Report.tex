\section{Executive Summary}

This report consolidates the full test history from the implementation and review session for Alex's dashboard feedback. It records the initial positive-path checks, every material defect uncovered during review, the corresponding corrective change, and the successful retest. The catalog contains \textbf{184 named test cases}; many cases contain multiple assertions.

\textbf{Final result.} The dashboard changes in Groups 1--9, including the two-tier variable configuration model and CLI unification, passed the final state described here. The final current-state smoke test produced:

\begin{itemize}
  \item Dashboard registration: \textbf{66 components / 27 callbacks}.
  \item Python compilation: all five modified source files compiled successfully.
  \item Sponsor estimator equivalence: \textbf{PASS}, with a scale-normalized coefficient gap of approximately $1.69\times10^{-8}$ in the final rerun.
  \item Model-window regression: 52-, 104-, and 156-week runs completed successfully.
  \item Three-year robustness: the 156-week run produced three model-year periods.
  \item Configuration hygiene: no config diffs and no upload temp, backup, or test override artifacts remained after verification.
\end{itemize}

\textbf{Important scope note.} The runtime/scaling benchmark requested verbally in the July meeting (1 model, 10 models, full set, and doubled run) is a separate deliverable and is not claimed as completed by this report. The screenshots had already been sent to Alex and are also outside this report's test scope.

\section{Defect Discovery and Retest Summary}

The session did not stop at happy-path verification. Review findings were converted into explicit regression tests. The most consequential defect families were:

\begin{enumerate}
  \item \textbf{Editor-to-run correctness:} Variables Run originally did not persist on-screen edits. The fix was retested with a concrete adstock change and with invalid bounds.
  \item \textbf{Slice context correctness:} Context originally checked only product. Channel and target gating were added and tested.
  \item \textbf{Configuration scope correctness:} Regenerate, Reset, no-channel fallback, and CLI resolution each had separate divergence or scope defects that were closed.
  \item \textbf{Callback ordering:} Independent Save/Reset/read callbacks created races. A post-write \code{config\_rev} dependency was introduced and all writers were verified.
  \item \textbf{Config authority:} Hidden CLI ACV forcing and the legacy root fallback could contradict the app. Both were removed and role-based behavior was tested in both directions.
  \item \textbf{Template failure safety:} Unknown names, duplicates, bad channels, case collisions, empty uploads, partial validation, staging failures, mid-commit failures, restore failures, and concurrency were all fault-injected.
  \item \textbf{Export failure safety:} New datasets, missing targets, colored grades, and all-failed workbooks were tested explicitly.
  \item \textbf{Modeling validity:} The first full-refit implementation allowed validation and reported models to select different structures. The final design selects structure without tail leakage and refits that same structure on full data.
  \item \textbf{Time-state correctness:} Contribution state clearing, 52-week Previous behavior, missing paths, map replacement, malformed dates, mixed formats, and A-vs-A comparison were each found during review and retested after repair.
\end{enumerate}
